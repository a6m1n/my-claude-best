# Security policy

The code in this repository that runs on your machine is [claude-config/statusline/statusline.py](claude-config/statusline/statusline.py), with the install commands and the one-paste prompt in [install.md](claude-config/statusline/install.md) that put it there. The script runs with your user's rights every time Claude Code refreshes the status line.

## Report a vulnerability

Report it privately: open the repository's Security tab (GitHub may label it "Security and quality") and choose "Report a vulnerability". Never put the details in a public issue, because a public issue shows the problem to everyone before a fix exists. If the button is not there, open an issue that says only that you have a security report, and I will open a private channel.

## Supported versions

Only the latest version on `main`. A fix lands there, and [install.md](claude-config/statusline/install.md) says how to copy the script to your machine again.
