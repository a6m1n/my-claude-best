# Contributing

This is a personal library: the practices say how one author works. Issues are welcome. Pull requests are open to collaborators only.

## Report a problem or ask a question

Open an issue. Name the file and the section, quote the line, and say what is wrong or unclear. When you think a fact is out of date, link the source that says so.

For the status line, add your operating system, the output of `python3 --version` and `claude --version`, and what step 1 of [install.md](claude-config/statusline/install.md#set-it-up-by-hand) prints.

Every name in an example here is fictional. Keep yours that way: no real company, person, path or ticket in an issue.

## Security problems

Never describe one in an issue. See [SECURITY.md](SECURITY.md).

## What happens next

I read the issues when I can. When I agree with one, I change the text myself and link the commit in the issue. There is no deadline.
